# 对话频率限制插件

`astrbot_plugin_rate_limiter` v1.3.0

限制每个用户/群聊在一定时间内的对话次数，超限后自动拦截。支持白名单豁免和按用户/群单独设限。

---

## 功能一览

| 功能 | 说明 |
|------|------|
| 私聊限制 | 每个 QQ 号每小时最多对话 N 次 |
| 群聊限制 | 每个群每小时最多对话 N 次（需要 @机器人） |
| 时间窗口 | 限制周期可自定义（默认 60 分钟） |
| 超限提示 | 超限后自动回复提示，含剩余等待时间 |
| 用户白名单 | 指定 QQ 号 → 不受任何限制 |
| 群聊白名单 | 指定群号 → 不受任何限制 |
| 用户单独限制 | 指定 QQ 号 → 用独立额度，不用全局默认 |
| 群聊单独限制 | 指定群号 → 用独立额度，不用全局默认 |
| 批量设置 | 多个 QQ 号/群号可以一次设同一个额度 |

---

## 配置方法

AstrBot WebUI → 插件管理 → 对话频率限制 → 配置

### 1. 全局默认（对所有人/群生效）

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 私聊限制次数 | 10 | 每个 QQ 号每小时上限 |
| 群聊限制次数 | 20 | 每个群每小时上限 |
| 时间窗口 | 60 分钟 | 限制周期 |
| 超限提示消息 | 你说话太快了... | `{remain}` 会替换为剩余时间 |

### 2. 白名单（不受限制）

**用户白名单** — 每行填一个 QQ 号：
```
601514573
123456789
```

**群聊白名单** — 每行填一个群号：
```
601514573
123456789
```

### 3. 单独限制（独立额度）

每行一条规则，格式：`QQ号:次数` 或 `QQ号1,QQ号2,QQ号3:次数`

**用户单独限制**：
```
601514573:50                         ← 一个 QQ 号限 50 次/小时
601514573,123456789,999999:30        ← 三个 QQ 号都限 30 次/小时
```

**群聊单独限制**：
```
601514573:100                        ← 一个群限 100 次/小时
601514573,123456789,111111:80        ← 三个群都限 80 次/小时
```

## 优先级规则

```
消息进来
  │
  ├─ QQ号 在用户白名单？        → ✅ 直接放行
  ├─ 群号 在群聊白名单？        → ✅ 直接放行
  │
  ├─ 该 QQ号/群号 有单独限制？  → 用单独的额度
  ├─ 没有单独设置？              → 用全局默认额度
  │
  ├─ 已达上限？  → ❌ 拦截，发送超限提示
  └─ 未达上限？  → ✅ 记录一次，放行
```

**场景 1：管理员不受限制**

用户白名单：

**场景 2：VIP 用户给高额度**

```
601514573:100
```

用户单独限制：

**场景 4：大群放宽**

群聊单独限制：
```
601514573:100
```

**场景 5：多个群同一额度**

群聊单独限制：
```
601514573,123456789,111111:80
```

## 执行逻辑说明

- 群聊中只有 **@机器人** 的消息才计数，普通聊天不受影响
- 超限后直接由插件回复提示，**不会调用 LLM**，不消耗 token
- 时间窗口过期后自动恢复，不需要手动操作
- 插件重启后计数清空（内存计数，不持久化）
- 同一 ID 在单独限制中出现多次，以最后一次为准
