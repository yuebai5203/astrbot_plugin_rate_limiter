# 对话频率限制插件

`astrbot_plugin_rate_limiter` v1.5.0

滑动窗口限制私聊/群聊对话次数：任意 `window_minutes` 分钟内超限即拦截，不再调用 LLM。
支持白名单豁免、按用户/群单独设限、真实解锁倒计时、额度用尽独立提醒、超限静默防刷屏。

---

## 功能一览

| 功能 | 说明 |
|------|------|
| 私聊限制 | 每个 QQ 号每小时最多对话 N 次（默认 10） |
| 群聊限制 | 每个群每小时最多对话 N 次，**整群共享额度**（默认 30，需 @机器人） |
| 滑动时间窗口 | 窗口长度可自定义（默认 60 分钟），最旧记录滑出即恢复一条额度 |
| 真实解锁倒计时 | 超限提示里的等待时间 = 最旧记录滑出的真实时刻，不虚报 |
| 额度用尽提醒 | 额度内最后一条放行时，**单独发一条消息**告知额度用完与最早可继续时间 |
| 超限静默期 | 提示/提醒发出后 N 秒内（默认 60）该会话消息一律不回复，防连发刷屏 |
| 用户白名单 | 指定 QQ 号 → 不受任何限制 |
| 群聊白名单 | 指定群号 → 不受任何限制 |
| 单独用户限制 | 总开关 + 默认条数 + 按用户覆盖，指定 QQ 号用独立额度 |
| 群聊单独限制 | 指定群号 → 用独立额度，不用全局默认 |
| 配置即时生效 | 所有配置每次请求实时读取，WebUI 修改后无需重启插件 |

## 配置方法

AstrBot WebUI → 插件管理 → 对话频率限制 → 配置

### 1. 全局默认（对所有人/群生效）

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 私聊限制次数 | 10 | 每个 QQ 号每小时上限 |
| 群聊限制次数 | 30 | 每个群每小时上限（整群共享） |
| 时间窗口 | 60 分钟 | 滑动窗口长度 |
| 提示后静默秒数 | 60 | 额度提醒/超限提示发出后，这段时间内该会话消息不回复 |
| 超限提示消息 | 本小时对话次数已用完（{used}/{limit}），最早 {remain} 后可继续聊天~ | 支持占位符 `{used}` `{limit}` `{remain}` |
| 启用私聊限制 | 开 | 总开关 |
| 启用群聊限制 | 开 | 总开关 |

`{remain}` 会格式化为真实剩余时间，例如 `58分10秒`、`9分59秒`、`30秒`。

### 2. 白名单（不受限制）

**用户白名单** — 每行填一个 QQ 号：
```
601514573
123456789
```

**群聊白名单** — 每行填一个群号：
```
601514573
123456789
```

### 3. 单独用户限制（独立额度）

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 启用单独用户限制 | 开 | 总开关；关闭后下方列表全部不生效，所有用户统一走全局私聊限制 |
| 单独用户限制次数（默认） | 20 | 列表中未单独写次数的用户，统一按此条数限制 |
| 单独限制的用户 | 空 | 列表，见下方填法 |

**单独限制的用户**列表三种填法可混用：

```
123456789                              ← 纯 QQ 号 → 使用上方默认次数（20 条/时）
999:50                                 ← QQ号:次数 → 该用户单独限 50 条/时，覆盖默认
111,222:30                             ← 批量 → 这两个 QQ 都限 30 条/时
```

### 4. 群聊单独限制（独立额度）

每行一条规则，格式：`群号:次数` 或 `群号1,群号2,群号3:次数`

```
601514573:100                        ← 一个群限 100 次/小时
601514573,123456789,111111:80        ← 三个群都限 80 次/小时
```

## 优先级规则

```
消息进来
  │
  ├─ QQ号 在用户白名单？        → ✅ 直接放行
  ├─ 群号 在群聊白名单？        → ✅ 直接放行
  │
  ├─ 启用单独用户限制 且 QQ号 有单独设置？ → 用该用户的额度（纯号=默认条数，QQ:次数=指定条数）
  ├─ 群号 有单独限制？          → 用该群的额度
  ├─ 都没有单独设置？           → 用全局默认额度
  │
  ├─ 额度已用完（静默期内）？   → 🔇 不回复（不重复提示，防刷屏）
  ├─ 额度已用完？               → ❌ 拦截，提示真实剩余等待时间
  └─ 还有额度？                 → ✅ 记录一次，放行（最后一条额度放行时单独发额度用尽提醒）
```

## 常见场景

**场景 1：管理员不受限制**

用户白名单：
```
601514573
```

**场景 2：几个 VIP 用户统一高额度（比如 50 条/时）**

启用单独用户限制：开；单独用户限制次数（默认）：50

单独限制的用户：
```
601514573
123456789
```

**场景 3：某个用户单独收紧/放宽**

单独限制的用户：
```
888888:5        ← 限制得很严
999999:100      ← 给得很宽
```

**场景 4：大群放宽**

群聊单独限制：
```
601514573:100
```

## 执行逻辑说明

- 群聊中只有 **@机器人** 的消息才计数，普通聊天不受影响；群额度为整群共享
- 超限后直接由插件回复提示，**不会调用 LLM**，不消耗 token
- **滑动窗口**：额度用尽后无需等满一个窗口——窗口内最旧一条记录滑出即恢复一条额度，倒计时提示的就是这个真实时刻
- **额度用尽提醒独立发送**：额度内最后一条消息放行时，提醒作为单独一条消息发出，不与 AI 回复拼接，也不打断正常回复
- **静默期**：额度提醒或超限提示发出后的静默秒数内，该会话消息一律不回复；静默结束后消息才恢复处理（仍未解锁则再次提示新倒计时，已解锁则正常对话）。群维度共享额度，故群内静默对整群生效
- 所有配置项（含白名单、单独限制、条数、窗口、静默秒数、提示文案）**实时读取，WebUI 修改即时生效**，无需重启
- 计数存于内存：AstrBot 或插件重启后计数清空（不持久化）
- 同一 ID 在单独限制中出现多次，以最后一次为准

## 变更记录

**v1.5.0**（当前版本）
- 新增「启用单独用户限制」总开关，关闭后单独用户限制全部不生效
- 新增「单独用户限制次数（默认）」：列表中纯 QQ 号统一使用该条数
- 列表支持三种填法混用：纯 QQ 号 / `QQ号:次数` / `QQ号1,QQ号2:次数`

**v1.4.0**
- 超限倒计时改为真实解锁时间（窗口内最旧记录滑出的时刻），不再虚报
- 额度用尽（放行最后一条额度）时单独发送一条提醒消息，不与回复拼接
- 新增超限静默期（默认 60 秒，可配置），静默期内消息不回复，防连发刷屏
- 白名单、单独限制改为每次请求实时读取配置，WebUI 修改即时生效
- 群聊默认上限 20 → 30
- 超限提示支持 `{used}` `{limit}` `{remain}` 占位符

**v1.3.0**
- 新增用户白名单、群聊白名单
- 新增用户单独限制、群聊单独限制
- 支持批量格式 `ID1,ID2,ID3:次数`

**v1.2.1**
- 群聊冷却时间基于最后一条消息计算

**v1.2.0**
- 使用 on_llm_request 钩子，不拦截插件指令
